## 3. Concrete Implementation Specifications

### Task 2.1: 24fps SMPTE Timecode Formatter (`24.frame.unit/buz/frame.buzz.ts`)

Export `frameToSmpteTimecode24(frameIndex: number, startClockHm?: string): string`:
- Reject negative `frameIndex` (`NEGATIVE_FRAME_INDEX`).
- Compute base start frame offset from `startClockHm` (when provided as `HH:MM`):
  `baseFrames = (hh * 3600 + mm * 60) * 24` (or `0` when omitted).
- Wrap total frames modulo `86400 * 24` (`2073600` frames/day):
  - `ff = total % 24`
  - `totalSeconds = Math.floor(total / 24)`
  - `ss = totalSeconds % 60`
  - `mmOut = Math.floor(totalSeconds / 60) % 60`
  - `hhOut = Math.floor(totalSeconds / 3600) % 24`
- Format zero-padded `HH:MM:SS:FF`.
- Populate `from_timecode: frameToSmpteTimecode24(from_frame)` and `to_timecode: frameToSmpteTimecode24(to_frame)` inside `quantizeShotTimeline` (with optional overload parameter `startClockHm?: string`).

### Task 2.2: Activate `25.episode.unit` Narrative Timeline Registry

Implement in `packages/400.conductor/25.episode.unit/`:
- `ANCHOR_EPISODE_CHRONOLOGY`: anchors `{ seriesSlug, startDate, startTimeHm, daypart, framesPerSecond: 24 }` onto `EpisodeModel` and resets `sceneTimeline = []`, `cumulativeFrames = 0`.
- `ADVANCE_EPISODE_SCENE`: records `{ sceneId, durationFrames, startTimeHm, startTimecode: frameToSmpteTimecode24(cumulativeFrames, startTimeHm), endTimecode: frameToSmpteTimecode24(cumulativeFrames + durationFrames - 1, startTimeHm) }` onto `sceneTimeline` and advances `cumulativeFrames += durationFrames`.

### Task 2.3: Exposure Sheet Chronology Stamping (`32.audio.unit`)

In `32.audio.unit/val/audio.val.ts` (`ExposureSheetDocumentSchema`), `fce/audio.interface.ts` (`ExposureSheetDocument`), and `buz/audio.buzz.ts`:
- Add optional `chronology`:
```typescript
chronology: z
    .object({
        start_date: z.string().regex(/^\d{4}-\d{2}-\d{2}$/),
        start_time_hm: z.string().regex(/^([01]\d|2[0-3]):[0-5]\d$/),
        start_timecode_smpte: z.string().regex(/^\d{2}:[0-5]\d:[0-5]\d:\d{2}$/),
        end_timecode_smpte: z.string().regex(/^\d{2}:[0-5]\d:[0-5]\d:\d{2}$/),
        daypart: z.enum(['DAWN', 'MORNING', 'AFTERNOON', 'DUSK', 'NIGHT']),
    })
    .strict()
    .optional(),
```
Ensure callers omitting `chronology` still produce completely valid legacy `ExposureSheetDocument` payloads!
