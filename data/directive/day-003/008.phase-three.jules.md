### Source Code Deliverables

#### 1. Create `packages/400.conductor/32.audio.unit/buz/foleyMatcher.buzz.ts`

Implement:
- `PARALLAX_FOLEY_REGISTRY`: Maps each of the 9 *Parallax Dinner* cue categories (`rain_squall`, `diesel_idle`, `door_hiss`, `booth_creak`, `menu_drop`, `coffee_pour`, `wipe_tear`, `lens_click`, `semi_pass`) to keywords and `>= 3` sample WAV paths (`foley/<category>/<cue>_v1.wav`, `_v2.wav`, `_v3.wav`).
- `mulberry32(seed: number): () => number`: Deterministic 32-bit PRNG returning `[0, 1)`.
- `matchActionLinesToFoleyPlacements(sceneId: string, actionLines: Array<{ text: string; frameOffset: number }>): FoleyPlacement[]`:
  - Scans each action line for matching Foley categories.
  - Computes `seed = murmurHash3("${sceneId}:${cueName}:${frameOffset}")` and picks `variantIdx = Math.floor(mulberry32(seed)() * variants.length)`.
  - **Anti-Clustering Rule:** If the same `cueName` was placed within the preceding `120` frames (`frameOffset - prevFrameOffset < 120`) and selected the same `sampleKey`, re-hashes with `:retry1` salt (`murmurHash3("${sceneId}:${cueName}:${frameOffset}:retry1")`) and advances `variantIdx` (`(variantIdx + 1) % variants.length`) so consecutive nearby cues never repeat the same WAV sample.
- `mergeCloseSpeechWindows(windows: Array<{ startFrame: number; endFrame: number }>, maxGapFrames = 18)`: Merges adjacent speech windows when `next.startFrame - current.endFrame <= maxGapFrames` (750 ms at 24 fps) to prevent ducking pump.
- `compileParallaxExposureSheet(sceneId = 'ep01_sc01')`: Quantizes all 34 *Parallax Dinner* dialogue turns at 24.0 fps (`Math.ceil((durationMs / 1000) * 24)`), resolves all 9 Foley placements from *The Parallax Dinner* action prose, computes the merged -14.0 dB quadratic ducking curve, and atomically writes `outputs/ep01_sc01/exposure_sheet.json` and `drafts/exposure_sheet.json`.

2. Triggering two identical Foley cues within `< 120` frames applies `:retry1` anti-clustering and selects two distinct `.wav` variants.
